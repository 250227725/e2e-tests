# Роли

Лёгкий реестр ролей и их подготовленных сессий. Заполняется и обновляется командой `/configure-roles`. Не является утверждённой документацией — не валидируется строго, только проверкой существования упомянутых AA (`document_authoring.py check-roles`). Формат — см. `role-configuration.md`.

*Не заполнено. Выполните `/configure-roles`.*
