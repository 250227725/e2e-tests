## Входные параметры

<Разделить параметры на списки «Обязательные» и «Необязательные». Для каждого параметра указать название. После названия допускается краткое описание, если само название не раскрывает семантический смысл параметра. Для необязательного параметра указать значение по умолчанию, если оно предусмотрено; при его отсутствии ничего не указывать. Если входных параметров нет — написать «Входные параметры отсутствуют».>

<Не указывай формат, тип данных или технические ограничения параметра (длина, маска, регулярное выражение и т.п.) — Action всегда получает готовое конкретное значение через TC. Если этот Action сам является генератором/источником данных — формат его результата описывается в разделе «Выходные данные» этого же документа, а не здесь.>

<Пример:>
```
- **<Название>** — {описание} {(`<значение_по_умолчанию>`)}
```
