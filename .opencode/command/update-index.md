---
description: Пересобрать индекс существующих TC и AA
---

Используй @.opencode/scripts/document_authoring.py.

1. Выполни `python3 .opencode/scripts/document_authoring.py inventory --kind tc --format json` и `--kind aa --format json`.
2. Для каждого TC определи статус реализации — наличие соответствующего файла теста (по фактической структуре `tests/` в проекте).
3. Для каждого AA определи статус реализации — наличие `actions/AA-<CODE>.ts`.
4. Сформируй `docs/index.md` целиком, по образцу:

```markdown
# Индекс

## Test Case

| Код | Название | Описание | Реализация |
|---|---|---|---|
| `TC-...` | ... | ... | ✅ / — |

## Atomic Action

| Код | Название | Назначение | Реализация |
|---|---|---|---|
| `AA-...` | ... | ... | ✅ / — |
```

5. Перезапиши `docs/index.md` целиком — это не утверждённая документация, согласование с пользователем не требуется.

Не изменяй TC, AA или их реализации. Только чтение и агрегация.
