---
description: Интерактивно создать новую спецификацию Atomic Action
---

Используй правила из @AGENTS.md и @.opencode/instructions/documentation-authoring.md.
Используй структуру @.opencode/templates/atomic-action.md.

Начальное описание пользователя:

$ARGUMENTS

Создай одну новую спецификацию Atomic Action в интерактивном режиме.

Определи вместе с пользователем:

- название и назначение;
- семантический код;
- входные параметры, их обязательность, формат и значения по умолчанию;
- последовательность шагов;
- варианты успешного результата;
- ограничение времени, если это бизнес-требование;
- выходные данные.

Проверь, что действие:

- является одним законченным действием;
- содержит только положительные варианты результата и позволяет однозначно подтвердить хотя бы один из них;
- не содержит основную проверку конкретного TC;
- не зависит от бизнес-сущности другого теста;
- не дублирует существующий AA с тем же смыслом.

Идентификатор: `AA-<CODE>`.
Целевой путь: `docs/atomic-actions/AA-<CODE>.md`.

Сохрани только последнюю полностью показанную и явно подтверждённую редакцию.
Не создавай другие файлы.
