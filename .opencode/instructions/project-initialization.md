# Инициализация и контекст проекта

## Область применения

Инструкция применяется только командой `/init-project`.

Разрешает создавать и обновлять исключительно раздел «Контекст проекта» в корневом `AGENTS.md`. Ничего другого не создаёт и не изменяет: не трогает никакие другие разделы `AGENTS.md`, не создаёт отдельных файлов, не запускает нативную команду `/init`.

## Интерактивный режим

Вопросы задаются по одному за сообщение — это осознанное исключение из общего правила батчинга вопросов (`documentation-authoring.md`, «Интерактивный режим»), не норма по умолчанию для остальных команд.

Не придумывай ответы, не выбирай наиболее вероятную трактовку — как и в `documentation-authoring.md`.

## Первый запуск

Раздел «Контекст проекта» пуст (плейсхолдер «Не заполнено»).

Задай по одному следующие вопросы:

1. Приложение является SPA, или переходы могут вызывать полную перезагрузку страницы?
2. Доступен ли API для подготовки тестовых данных, или подготовка выполняется строго через UI?
3. Есть ли бизнес-сущности, которые нельзя создать через UI и нужно использовать как готовые? Если да — перечислить, какие.
4. Как называются переменные окружения для базового URL и учётных данных?
5. Отличается ли расположение документации от `docs/atomic-actions/` и `docs/test-cases/` по умолчанию?
6. Есть ли в проекте уже линтер, форматтер и генератор тестовых данных, или подключить рекомендуемые ESLint, Prettier и Faker?

После сбора всех ответов покажи полный текст предлагаемого раздела «Контекст проекта», запроси подтверждение, только после этого сохрани.

## Повторный запуск

Раздел уже заполнен.

Покажи пользователю текущее содержимое раздела. Спроси, что изменилось — одним открытым вопросом, не повторяя весь список из 6 пунктов заново.

Обнови только затронутые пункты. Покажи полный новый текст раздела целиком, запроси подтверждение перед сохранением.

## Механизм записи

`AGENTS.md` не обслуживается `document_authoring.py` (скрипт работает только с `docs/atomic-actions/` и `docs/test-cases/`). Запись выполняется прямым редактированием файла: замени содержимое между заголовком `## Контекст проекта` и следующим заголовком того же уровня (`##`) на новый текст. Не задевай никакой другой текст файла.

## Ограничения

- Не создавай отдельных файлов для контекста проекта.
- Не изменяй никакие другие разделы `AGENTS.md`.
- Не запускай нативную команду `/init`.
- Раздел «Контекст проекта» не подлежит ручному редактированию вне этой команды — при необходимости изменить содержимое всегда выполняется `/init-project` повторно.

## Завершение

После сохранения сообщи, что раздел «Контекст проекта» сформирован или обновлён, и кратко перечисли, что изменилось (при повторном запуске).
