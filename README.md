# Фреймворк разработки E2E-тестов

Проект представляет собой самостоятельный фреймворк для организации разработки E2E UI-тестов на Playwright Test и TypeScript. Он задаёт единый подход к описанию Test Case (TC), Atomic Action (AA), исследованию интерфейса, хранению селекторов, реализации тестов и диагностике результатов. Фреймворк предназначен для подключения к тестируемому проекту и адаптации под его фактическую структуру, окружения и бизнес-сценарии.

В состав фреймворка входят команды OpenCode, инструкции, шаблоны и Python-скрипты. Команды `/create-aa` и `/create-tc` управляют созданием документации, `/research-tc`, `/implement-tc` и `/run-tc` обеспечивают разработку отдельных сценариев, а `/check-test-dependencies` и `/run-all-tests` отвечают за проверку зависимостей и полный запуск тестов.


Фреймворк обеспечивает независимость тестов, подготовку данных через UI, безопасную работу с утверждённой документацией и централизованное управление зависимостями между TC, AA и проверочными сценариями. 

Для использования:
1. Создайте .env.dev с базовыми настройками подключения к системе
2. Откройте `opencode` и выполнитье запрос: `Исследуй проект, установи необходимые компоненты для создания тестов на playwright test с использованием typescript. Включи LSP`
3. Создавайте тесты
